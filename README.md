# Pixeltown

Pixeltown is a retro-looking pixel-art city-building video game
inspired by SimCity.

## How to Build/Run PixelTown?

This project is built by [xmake](https://xmake.io/guide/quick-start.html).

To build it, run 

```
$ xmake
```

To run it, run

```
$ xmake run
```
